# 🏥 Family Tracker EHR

A blockchain-based **Electronic Health Record (EHR)** system built with **Streamlit** that allows **patients** and **doctors** to manage health data securely.

---

## 📌 Features
- 👩‍⚕️ **Doctor & Patient Dashboards**
- 🔐 **Secure Login System** with wallet authentication
- 📂 **Upload & Store Medical Records** securely
- ⛓ **Blockchain Integration** using smart contracts
- ☁️ **IPFS Support** for decentralized storage
- 📧 **Email Notifications** for updates
- 📊 **Interactive Streamlit UI**
